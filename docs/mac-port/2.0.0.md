# Open Note 2.0.0 (the flower version): what the Mac app must follow

> Bản 2.0.0 thêm: AI agent (lệnh `opennote-ai`), màu chữ, lưu note thành `.txt` / `.onote`, đánh dấu bằng hoa, thiệp hướng dẫn mới có lá thư, note "có gì mới" sau khi cập nhật, và nhiều sửa lỗi. Dưới đây là danh sách việc cho bản Mac, theo từng file Windows.

- From: **1.1.0** (`8c3f10c`). To: **2.0.0** (`5feda5b`). Full diff: `git diff 8c3f10c..5feda5b -- src/OpenNote tests`
- Screens: [`docs/screens/`](../screens/README.md). Art: `src/OpenNote/Assets/help/*`, `src/OpenNote/Assets/marks/*` (reuse the files as they are).
- After porting, the Mac app's version is **2.0.0**.

## 1. Data: new fields (a Windows `notes.json` / `settings.json` must open unchanged)

- [ ] `Note.mark` (string, default `""` = the star). Flower ids: `pink`, `yellow`, `blue`, `red`, `daisy`, `clover` (`Core/NoteMarks.cs`). Kept when the mark is taken off.
- [ ] `AppSettings.allowAgents` (bool, default `true`), `noteStyle` (string, default `""`), `whatsNewSeen` (string, default `""`).
- [ ] Settings that can't be read: stand-in defaults now have `allowAgents = false`, and Reload settings keeps the current `allowAgents` / `noteStyle` when the file can't be read (`AppSettings.Load`, `App.ReloadSettings`).
- [ ] Nulls inside settings lists (`"aiServices": [null]`, `[null, "k"]` in keys or models) are dropped when reading (`AppSettings.Read`, `NoBlanks`).
- [ ] Note text may now hold color tags `{red}…{/}` (see 2). Old notes are unchanged.

## 2. Text color (`Core/InlineMarkup.cs`, `Core/Palette.cs`, `Views/RichText.cs`, `Views/NoteWindow*.cs`)

- [ ] Markup: `{red}text{/}`, `{orange}`, `{green}`, `{blue}`, `{purple}`; `\{` escapes a tag. Port `Parse`, `Write`, `Strip` exactly, including the fast paths and the rule that stops searching for `{/}` once none is left (no quadratic time on many unclosed tags).
- [ ] `Palette.TextColors`: name, ink on light paper, ink on dark (Graphite) paper.
- [ ] Ctrl+H toggles the last color on the selection; right-click → **Text color** submenu with the 5 colors and **No color**.
- [ ] **Owner question:** `⌘H` is the system "Hide" on macOS. Which key for text color on the Mac (for example `⌘⇧H`)? Add the answer to `mac/DIFFERENCES.md`.

## 3. Flower marks (`Core/NoteMarks.cs`, `Views/NoteWindow.xaml(.cs)`, `Views/NoteWindow.Menus.cs`)

- [ ] Clicking the star opens a small round popup: the star plus six flowers, and ✕ (remove) when the note is marked. Screen: `07-mark-picker.png`.
- [ ] The star keeps its old effect; a flower shows its picture in the corner with a short spin (no spin when reduce motion is on).
- [ ] Ctrl+Shift+S puts the last mark back or takes it off. Important notes still sort first.

## 4. Save as file and `.onote` (`Core/NoteFile.cs`, `Views/NoteWindow.Menus.cs`, `App.xaml.cs`, `Services/TrayService.cs`)

- [ ] Note menu → **Save as file…**: `.onote` (everything) or **Text only** `.txt`. A copy; the note stays.
- [ ] `.txt`: title as typed (no markup parsing), blank line, text without marks, a picture becomes `[image]`, UTF-8 without BOM, CRLF line ends.
- [ ] `.onote`: the same JSON as `NoteFile.ToOnote` (camelCase, `format: "Open Note"`, `version: 1`, pictures as base64 keyed by `images/<32 hex>.png|jpg`). Reading refuses other files, newer versions and files over 200 MB; drops unsafe paths and data that isn't PNG/JPEG; clamps opacity, font size and size; gives the note a new id.
- [ ] Writing is atomic (temp file then replace); a picture that can't be read stops the save with a message; a note too big to reopen is refused.
- [ ] Opening: tray menu → **Open a note file…** (several at once), and a double-click on an `.onote` file. A second launch with a file hands it to the running app. Imported notes open at the mouse, in front.
- [ ] Mac: declare the `.onote` document type (`CFBundleDocumentTypes` + an exported UTI) and handle `application(_:open:)`; macOS sends a double-clicked file to the running copy by itself, so no pipe is needed for this. Add that line to `mac/DIFFERENCES.md`.

## 5. AI agents: the `opennote-ai` command (`Core/AgentCommands.cs`, `Services/AgentServer.cs`, `Program.cs`, `Views/HelpWindow.*`)

- [ ] Port `AgentCommands` exactly: the guide text, commands (`list`, `search`, `read`, `new`, `add`, `style`), options, limits, messages and exit codes. It is Core logic with tests (`AgentCommandsTests`).
- [ ] The command talks to the running app, starting it if needed; agents can never delete or rewrite a note; a locked note can't be added to; nothing works while `allowAgents` is off.
- [ ] How-to card → **AI agents** page: the two prompts with Copy, the note style box (saved when the card closes, only if edited), the allow checkbox. Screen: `03-how-to-card-ai-agents.png`.
- [ ] **Owner question:** the Mac transport and install. Windows uses a named pipe only this user can open and puts `opennote-ai` on PATH (installer) or an app alias (Store). Suggested for the Mac: a Unix domain socket in the data folder with `0600` permissions, and a command-line tool inside the app bundle that the user links into `PATH`. Decide before porting, then add it to `mac/DIFFERENCES.md`.
- [ ] Mirror the fix: the server waits for the client to read its answer only until the 30 s deadline (a client that never reads can't block the next one).

## 6. The how-to card redesign (`Views/HelpWindow.xaml(.cs)`, `Assets/help/*`)

- [ ] New look: torn handmade paper, daisies in both bottom corners, a heart top right, the red "OPeN NoTe" title picture, olive headings `#4A5E32`, brown keys `#6B4E3D`, text `#3A3128`. 840×670 DIP layout from the XAML. Screens `02`–`04`.
- [ ] The bag of flowers sways on its strap (15 fps), with the little envelope tucked under it that grows on hover and nudges every 4 s; a click shows the letter (`letter-card.jpg` on `letter-shadow.png`, tilted −2.5°).
- [ ] On the letter: a **♪ Listen to Locked Away** button that opens the song's YouTube link (`HelpWindow.SongUrl`); the app ships no music.
- [ ] A feedback line in the empty space: "If you have any thoughts or feedback, I'd love to hear from you at {0}, call me Gem or NhatDat <3" with the address in olive.
- [ ] On a small or highly scaled screen the whole card scales down to fit.

## 7. The "what's new" note (`Services/NoteManager.cs`, `App.xaml.cs`)

- [ ] After an update, once: a note in the middle of the main screen (400×440 DIP) listing what's new, in the display language. Shown only after `whatsNewSeen` has been saved as `NoteManager.WhatsNewId` (`"flower"`), so it never comes back, even when deleted. A first run sets it without showing the note. Screen: `13-whats-new-note.png`.

## 8. Fixes to mirror (same behavior on the Mac)

- [ ] A title still being typed (F2) is kept when the note is closed or archived (a titled blank note used to be deleted).
- [ ] Startup picture cleanup keeps pictures named in `notes.json.bak` or a set-aside `notes.corrupt-*` file, and skips cleaning when one of them can't be read.
- [ ] Quit (tray Exit, `Ctrl+Alt+Q`) asks first when the notes couldn't be saved; `--exit` (used by updates) still quits without asking.
- [ ] A note whose header is off screen is brought back even if the shadow margin is visible: `ScreenMath.EnsureVisible(..., topInset)` with the 12 DIP margin.
- [ ] Two copies starting at once while moving the old `DeskNotes` folder use the moved folder (Windows only: no DeskNotes on the Mac, nothing to port).

## 9. Texts (`Core/Translations.cs`)

- [ ] 53 new rows (all 7 languages): text color, marks, save/open files, AI agents, the letter and feedback line, what's new, the quit warning. Port row by row; `TranslationTests` now also checks that keys are unique.

## 10. Tests to port (`tests/OpenNote.Tests/`)

- [ ] New: `NoteFileTests`, `AgentCommandsTests`.
- [ ] New cases in `InlineMarkupTests` (color tags, escapes, many unclosed tags), `NoteStoreTests` (mark, settings with nulls, unreadable settings keep agents off), `PictureTests` (cleanup keeps backup pictures), `ScreenMathTests` (shadow margin), `TranslationTests` (unique keys), `RichTextTests` (colors).

## Not ported (Windows only)

- MSIX and Inno Setup file association and PATH entries, the console copy of the exe (`MakeConsoleCopy`), memory trimming, the DeskNotes migration.
