# Open Note 2.0.0 screens (Windows)

Screenshots of the Windows app, the reference for the macOS port. Sizes, colors and texts come from the code in `src/OpenNote/Views/` (the XAML); these pictures show how it looks. Taken at 125% scaling with English as the display language, from a clean data folder.

| File | What it shows |
|---|---|
| `01-first-run-language-picker.png` | First start: pick the display language |
| `02-how-to-card-shortcuts.png` | How-to card (`Ctrl+Alt+/`), shortcuts page, with the feedback line |
| `03-how-to-card-ai-agents.png` | How-to card, AI agents page: prompts to copy, note style, allow checkbox |
| `04-how-to-card-letter.png` | The letter that opens from the bag, with the song button |
| `05-welcome-note.png` | The welcome note made on the first start |
| `06-desktop-notes.png` | Notes: colors, checklist, bold/italic/text colors, bullets, the graphite note, an opened `.onote` note with a picture and a flower mark |
| `07-mark-picker.png` | Clicking a note's star: the star and six flowers |
| `08-note-menu.png` | The note's `⋯` menu (colors, glass, text size, font, Save as file…) |
| `09-right-click-menu.png` | Right-click in a note: text colors and the other commands |
| `10-all-notes-and-archive.png` | All notes and archive (`Ctrl+Alt+M`) |
| `11-ai-languages-and-keys.png` | AI languages and keys (`Ctrl+Alt+K`) |
| `12-choose-notes-to-keep.png` | Choose notes to keep (`Ctrl+Alt+P`) |
| `13-whats-new-note.png` | The "what's new" note shown once after an update |

The art used on these screens is in `src/OpenNote/Assets/help/` and `src/OpenNote/Assets/marks/`; reuse those files.
